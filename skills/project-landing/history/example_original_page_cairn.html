What's inside

Cairn in three ideas.

01

Plain files, no lock-in

Ideas, tasks, decisions, notes and a journal as Markdown in a brain/ folder. Delete Cairn and it still reads fine on GitHub, in Obsidian or in VS Code.

02

One loop, one place

Capture from anywhere, brainstorm on the Ideas wall with spark prompts, log decisions, then drag tasks from To do to Done.

03

Knows your code

Turns TODO and FIXME comments into tasks that remember the file and line, commits the brain in one click, and writes a context brief for AI assistants.

Questions

Good questions.

Is it free?

Yes. The source is public on GitHub under the MIT licence.

How is it different from Obsidian or Notion?

Notion lives in its own cloud, so your repo can't see it. Obsidian is great at linking notes but knows nothing about your project. Cairn keeps everything in the repo as plain files, so it works alongside both and adds the project loop: an ideas wall, a task board, a decision log, a code TODO inbox and a context pack.

Does it work with my AI assistant?

Yes. The context pack writes brain/CONTEXT.md, a short brief of what's in progress, what's next and which decisions are in force. Point Copilot, Claude, Cursor or ChatGPT at it. No API keys involved.

Where is my data?

In your repo, as Markdown. The demo keeps data only in your browser. The local app listens on 127.0.0.1 only.
